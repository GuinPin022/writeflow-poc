WriteFlow — Guide testeurs

Installer le plugin Word · suivre ton écriture · ton tableau de bord

Merci de participer au test de WriteFlow 🙏 Ce guide explique comment créer ton compte, installer le plugin Word (PC, Mac ou navigateur), suivre ta production et consulter ton tableau de bord en ligne. Le suivi fonctionne dans Word ; si tu crées un compte, tes statistiques se synchronisent pour apparaître sur le tableau de bord web — rien d'autre n'est partagé tant que tu ne rends pas ton profil public.

1 Créer ton compte

À la première ouverture du panneau WriteFlow dans Word, un écran de connexion s'affiche. Trois choix :

  • Créer un compte → saisis un email + un mot de passe, puis Se connecter. Ton suivi est alors synchronisé et visible sur le tableau de bord web.
  • Se connecter → si tu as déjà un compte (même identifiants partout : add-in et site web).
  • Utiliser sans compte (local) → tout reste sur cet appareil, rien n'est envoyé. Parfait pour essayer, mais le tableau de bord web restera vide (il lit les données du compte).
👉 Pour profiter du tableau de bord en ligne, crée un compte et utilise les mêmes identifiants dans Word et sur le site.

2 Installer le plugin Word

Tu n'as rien à compiler ni à installer comme logiciel. Il te faut seulement un compte Microsoft 365 avec Word.

👉 Le plus simple : utilise Word sur le web (ci-dessous). Si tu préfères Word installé sur ton ordinateur, un script t'évite toute la configuration manuelle — voir Mac / Windows plus bas.

🌐 Word sur le web Recommandé · tout OS

Rien à installer sur ta machine, pas de redémarrage.

  1. Télécharge le manifeste : manifest.github.xml
    (ou clic droit → « Enregistrer le lien sous… »).
  2. Ouvre un document sur word.office.com.
  3. Onglet Accueil → Compléments → Plus de paramètres.
  4. Charger mon complément → sélectionne le manifest.github.xml téléchargé.

🍎 Word Desktop — Mac script auto

  1. Télécharge le script : installer-writeflow-mac.command.
  2. Double-clique dessus. (Si macOS bloque : clic droit → Ouvrir → Ouvrir.) Le script copie tout seul le manifeste au bon endroit.
  3. Ferme et rouvre Word → onglet Accueil → Compléments → WriteFlow apparaît.
Si le double-clic affiche « permission refusée », ouvre le Terminal et tape : chmod +x ~/Downloads/installer-writeflow-mac.command, puis double-clique à nouveau.

🪟 Word Desktop — Windows script auto

  1. Télécharge le script : installer-writeflow.ps1.
  2. Clic droit dessus → « Exécuter avec PowerShell ». Le script crée le dossier, télécharge le manifeste et déclare le catalogue de confiance — sans droits administrateur.
  3. Ferme et rouvre Word → onglet Accueil → Compléments → (Avancé →) DOSSIER PARTAGÉ → choisis WriteFlow.
Si Windows bloque l'exécution du script, fais clic droit → Propriétés → coche « Débloquer » en bas, valide, puis relance.
Installer Mac/Windows à la main (sans script)

Mac : copie manifest.github.xml dans ~/Library/Containers/com.microsoft.Word/Data/Documents/wef (crée le dossier s'il manque), puis redémarre Word. (Finder → menu Aller → Aller au dossier… pour coller le chemin.)

Windows :

  1. Place manifest.github.xml dans un dossier (ex. C:\WriteFlow\).
  2. Word → Fichier → Options → Centre de gestion de la confidentialité → Paramètres du Centre… → Catalogues de compléments approuvés.
  3. Ajoute le chemin du dossier, coche « Afficher dans le menu », valide, redémarre Word.
  4. Onglet Accueil → Compléments → Avancé → DOSSIER PARTAGÉ → choisis WriteFlow.

3 Activer le suivi

  1. Ouvre le panneau WriteFlow (bouton dans l'onglet Accueil) et connecte-toi (étape 1).
  2. Va sur l'onglet Document et active l'interrupteur « Suivi d'écriture » (il passe sur Actif). Le suivi relève ta production toutes les 30 secondes.
  3. Écris normalement 🙂 Tes statistiques s'accumulent par jour et par document, et remontent toutes seules si tu es connecté.

Le panneau a quatre onglets :

  • Document — l'interrupteur de suivi, l'avancement du document ouvert (mots / cible), ton objectif du jour avec les paliers, le graphe des 7 derniers jours et un mini-calendrier.
  • Global — tes totaux tous documents confondus : aujourd'hui, la semaine, le calendrier 12 semaines, ton record, ta moyenne, le nombre de documents et de jours actifs.
  • Réglages — les objectifs et l'apparence du document (voir étape 4).
  • POC — vue technique de mesure (réservée aux tests) ; tu peux l'ignorer.
Le bouton 📊 Tableau de bord en haut du panneau ouvre ton tableau de bord web dans le navigateur.

4 Régler tes objectifs

Dans l'onglet Réglages du panneau (le suivi doit être actif pour identifier le document ouvert). Les objectifs sont propres à chaque document :

  • Quotidien (mots) — ta cible d'écriture par jour.
  • Hebdo (mots) — ta cible sur la semaine.
  • Total du document (mots) — la longueur visée du projet (barre d'avancement).
  • Échéance (deadline) — une date butoir ; l'onglet Document affiche les jours restants.
  • Thème des paliers — change les emojis et noms des paliers affichés sur l'onglet Document.

Tout en bas, « Réinitialiser l'historique » efface tes statistiques locales et tes objectifs. Sans effet sur tes fichiers Word.

5 Ton tableau de bord web

Le tableau de bord est un site qui affiche tes statistiques. Plus besoin d'exporter/importer un fichier : connecte-toi avec le même compte que dans Word, tes données sont déjà là.

👉 Lien à mettre en favori : Ouvrir le tableau de bord

Connecte-toi (mêmes email + mot de passe que l'add-in). Quatre onglets :

  • Vue d'ensemble — objectif du jour, séries (streaks), record, badges et paliers. Un sélecteur en haut permet de voir un document précis ou tous les documents.
  • Tableau — l'historique jour par jour, avec un filtre de dates (laisse les deux champs vides pour tout voir).
  • Paramètres — voir ci-dessous.
  • Profil — ton profil public (étape 6).

Onglet Paramètres

  • Heure de bascule de journée — l'heure à laquelle un nouveau jour d'écriture commence (ex. « 04 h » : ce que tu écris après minuit et avant 4 h compte sur la veille). Non rétroactif, et s'applique aussi dans Word après rechargement.
  • Réglages par document — mêmes objectifs que dans Word (quotidien, hebdo, total, échéance, thème), plus : définir un document par défaut, masquer un document, importer un historique CSV, exporter un document en CSV, fusionner deux documents ou en supprimer un.
  • Importer un historique (nouveau document) — pour ajouter un projet que tu ne suis pas dans Word (archive) à partir d'un fichier CSV.
Le tableau de bord se met à jour tout seul quand tu écris dans Word (avec le suivi actif et un compte). Si rien n'apparaît, vérifie que tu es connecté au même compte des deux côtés.

6 Profil public optionnel

Dans l'onglet Profil, tu peux te créer une page publique façon « Strava de l'écriture » pour partager ta progression — désactivée par défaut.

  1. Choisis un pseudo (3 à 30 caractères), puis éventuellement un nom affiché et une bio.
  2. Active Profil public : un lien partageable apparaît (de la forme …/dashboard/#/u/ton-pseudo) — copie-le ou ouvre-le.
  3. Choisis carte par carte ce qui est visible : aujourd'hui, X derniers jours, semaine, graphe, séries, meilleur jour, paliers, avancement du projet. Pour chaque carte : Masqué, Mots (l'effort sans dévoiler ton objectif) ou Complet (avec l'objectif).

Tant que ton profil est privé, personne ne voit rien. Tu peux aussi autoriser (ou non) les visiteurs à voir le détail d'un document précis.

7 Mises à jour

Quand une nouvelle version du tableau de bord est publiée, l'adresse ne change pas : recharge simplement la page (Ctrl + F5 sur PC, Cmd + Maj + R sur Mac) pour avoir la dernière version.
